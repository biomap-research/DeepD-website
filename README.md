# DeepD website

Official homepage for **DeepD**, a sparse mixture-of-experts genome foundation model for efficient long-context DNA modeling and controllable sequence generation.

- Website: <https://biomap-research.github.io/DeepD-website/>
- Preprint (bioRxiv): <https://doi.org/10.64898/2026.10.13.758170>
- Code, notebooks and API usage guide: <https://github.com/biomap-research/DeepD>
- Request an API key: <https://biomap-research.github.io/DeepD-website/#api>

Plain HTML, CSS and JavaScript with no build step. Open `index.html` locally or serve the folder with any static file server.
